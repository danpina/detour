# House style for generated illustrations

Edit this file to change the look of every generated image. The text under "Prompt template" is sent to the
image-generation API with `{{show}}` replaced by the image brief of the card.

Rules that always apply (see CLAUDE.md rule 2): illustrations only, never photorealistic, never real people,
never real historical or scientific events, no text or lettering in the image, no logos.

## Prompt template

Editorial illustration, flat colours with soft grain, bold simple shapes, warm limited palette (deep teal, burnt
orange, cream, charcoal), generous negative space at the top and bottom for text overlay, portrait 4:5 composition.
Subject: {{show}}.
Not photorealistic. No text, no letters, no logos, no recognisable real people.
